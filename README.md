# Proverka29

PHP 8.1+ веб-приложение для обычного хостинга REG.RU. Приложение использует PHP-сессии и JSON-файлы для хранения пользователей, заявок, записей реестра и истории проверок.

## Установка на REG.RU

1. Сделайте резервную копию текущих файлов сайта и каталога `storage/`, если они уже существуют.
2. Загрузите `index.php` в корневой каталог домена (например, `www/proverka29.ru/`).
3. До первого запуска замените значение `ADMIN_SETUP_KEY` в локальной копии `index.php` на длинный случайный секрет. Не публикуйте этот секрет в GitHub и не отправляйте его в чат.
4. Убедитесь, что PHP может создавать и изменять каталог `storage/` рядом с `index.php`.
5. Включите HTTPS в панели REG.RU.
6. Откройте `https://proverka29.ru/?page=setup`, создайте администратора и войдите.

Если на сайте уже есть данные в `storage/`, не удаляйте и не заменяйте этот каталог при обновлении. Сначала сделайте резервную копию.

## Требования

- PHP 8.1 или новее.
- Расширения `json`, `fileinfo` и `mbstring`.
- Поддержка PHP-сессий и файловых блокировок (`flock`).
- Права на запись в `storage/` и `storage/uploads/`.

## Хранение и безопасность

Данные приложения хранятся в JSON-файлах внутри `storage/`. Приложение создаёт правила запрета доступа через `.htaccess` и индексные файлы-заглушки. На сервере, который не обрабатывает `.htaccess` (например, при прямой раздаче через Nginx), этого недостаточно: разместите `storage/` вне публичного корня сайта либо настройте запрет доступа к нему в конфигурации хостинга. Не открывайте сайт для регистрации реальных пользователей, пока не проверили, что JSON-файлы недоступны по прямым URL.

POST-запросы сериализуются файловой блокировкой, чтобы уменьшить риск потери изменений при одновременной записи. Для входа действует ограничение после пяти неудачных попыток в рамках одной сессии. Это дополнительная мера, а не полноценная защита от распределённых атак.

## Возможности и ограничения

- Регистрация и вход пользователей.
- Личный кабинет и отправка заявок.
- Административная обработка заявок.
- Публикация записей в публичном реестре.
- Базовая эвристическая проверка загружаемых файлов до 5 МБ.

Сканер ищет некоторые подозрительные фрагменты кода и расширения файлов. Он не использует антивирусные сигнатуры, не распаковывает архивы и не гарантирует безопасность файла. Не называйте его полноценным антивирусом и не используйте результат «явных признаков не найдено» как подтверждение безопасности.
